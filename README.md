# 🌹允许复制🌹 (Allow Select & Copy)

一个油猴/脚本猫用户脚本，解决网页禁止选择、禁止复制的问题。

## 配置方式

脚本分为**单次生效**与**全局生效**两种模式：

- **单次生效（菜单）**：点击脚本菜单中的「CSS允许选择 / 允许选择 / 允许复制」等命令，仅对当前页面生效，刷新后失效。
  ![菜单](https://dk-bucket.dominic.dpdns.org/picgo/2026/09/021522-656.png)

- **全局生效（用户配置）**：在脚本的用户配置中勾选对应复选框，配置被持久保存，每次打开新页面都会自动应用；取消勾选即停用。
  ![用户配置](https://dk-bucket.dominic.dpdns.org/picgo/2026/09/021518-d92.png)

## 功能一览

脚本提供了五种解锁方式，通过**脚本菜单**或**用户配置**触发：

| 模式 | 说明 | 副作用 |
|------|------|--------|
| CSS允许选择 | 仅通过 `user-select: auto` 允许选择，不处理事件阻止 | 极小 |
| 允许选择 | 允许选择，并移除 `selectstart` / `mousedown` 事件阻止 | 较小 |
| 允许复制 | 允许复制，并移除 `copy` / `cut` 事件阻止 | 较小 |
| 强制允许选择 | 激进重置样式，确保选择功能可用 | 可能影响页面布局 |
| 强制允许复制 | 激进重置样式，确保复制功能可用 | 可能影响页面布局 |

## 安装使用

1. 安装脚本（需要脚本猫或 Tampermonkey）。
2. 到被限制的网页上：
   - 点脚本菜单快速解锁当前页；或
   - 打开脚本的用户配置，勾选想要的模式实现全局持久生效。
3. 切换模式后，页面会以轻提示（非阻塞弹窗）告知已生效。
  ![生效提示](https://dk-bucket.dominic.dpdns.org/picgo/2026/09/021523-db7.png)

## 技术说明

- 基于脚本猫 UI 库（Arco）实现提示弹窗；样式、事件监听器均可恢复，不会永久污染页面。
- 菜单触发的为单次生效，配置勾选保存的状态在上一次页面与以后都保持。

## 兼容性

Chrome / Edge / Firefox / Safari / Opera 均支持（需对应油猴扩展）。
